# Security

## Reporting an issue with this hub

This repository is a community resource hub. It contains static pages, a
README, and a reference index. The hub is a small static site with no
runtime, no user data, and no network input.

If you spot a problem with the hub itself, open an issue on this repository
or contact the `deepaash` account on GitHub.

## Reporting a security issue in DeskVNC itself

DeskVNC is a separate project maintained at
<https://github.com/psmux/DeskVNC>. Any security issue in the DeskVNC client,
the `dvv` MCP server, or the protocol cores belongs there, not here.

Please follow the DeskVNC project's own security reporting process:

- Read <https://github.com/psmux/DeskVNC/blob/main/SECURITY.md>
- Use the GitHub private vulnerability reporting form at
  <https://github.com/psmux/DeskVNC/security/advisories/new>

Do not open a public issue for security problems in DeskVNC itself.

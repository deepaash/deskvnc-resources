# Contributing

Thanks for your interest in this resource hub.

This repository is a community curated reference for DeskVNC, the native
VNC, RDP and SSH client with an MCP control plane. It collects a quickstart,
the MCP tool surface, verified benchmarks, and links to the official project
page and source.

## How to help

Corrections and additions are welcome. Useful contributions include:

- Fixing outdated facts, broken links, or wrong benchmark figures
- Adding a use case guide that complements the official documentation
- Improving the MCP reference with examples that come from real use
- Spotting a host protocol or feature that the hub describes incorrectly
- Translating the quickstart or MCP reference

Open an issue first for larger additions so we can agree on scope. Small
corrections can go straight to a pull request.

## What belongs upstream, not here

Bug reports, interoperability findings, and pull requests for DeskVNC itself
belong in the main project at <https://github.com/psmux/DeskVNC>. Start with
its <https://github.com/psmux/DeskVNC/blob/main/CONTRIBUTING.md>.

## Ground rules

- Keep facts traceable to the DeskVNC README, the official project page, or a
  cited real world test.
- Do not invent testimonials, user counts, awards, or coverage.
- Frame capabilities affirmatively.
- Avoid em dashes and en dashes. A single ASCII hyphen is fine for compound
  modifiers and bullet lists.

By contributing, you agree your contribution is MIT licensed under this
repository's terms.
